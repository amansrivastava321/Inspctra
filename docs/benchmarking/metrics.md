# Benchmark Metrics

`DetectionMetrics` computes aggregate and per-app metrics:

1. issue coverage
2. false positives and false-positive rate
3. duplicate findings and duplicate rate
4. runtime verification rate
5. evidence completeness

## Metric usage

These metrics feed:

1. benchmark reports
2. adaptive audit planning
3. learning optimization recommendations

The metric set is intentionally deterministic and artifact-backed so benchmark comparisons remain reproducible.
