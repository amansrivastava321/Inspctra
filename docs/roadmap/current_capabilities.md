# Current Capabilities

QA-AI can currently:

1. run end-to-end deterministic audits through CLI-driven workflow orchestration.
2. coordinate multi-phase audit engines and persist outputs via ArtifactStore.
3. validate known artifact contracts through ArtifactValidator and schema families.
4. run runtime-lab readiness/live benchmark flows with planning-first safety controls.
5. simulate distributed runtime behavior (multi-actor, concurrency, offline/sync, chaos-safe).
6. orchestrate mobile runtime planning (device registry, Flutter/Appium/Maestro planning, mobile evidence).
7. run AI reasoning as advisory, deterministic-first, evidence-linked outputs with fallback mode.
8. generate executive/technical/dashboard/report export artifacts.
9. run continuous improvement loop components and benchmark metrics/trend signals.
10. use Graphify summaries/graph metadata in reporting and reasoning context.
